# Zoxiro

**The Operating Platform for Real Estate Investors.**

Zoxiro turns your own connected accounts — Gmail, Google Drive, Google Calendar,
your CRM — into a working back office: daily inbox handling, deal screening,
underwriting, and a pipeline you don't have to keep by hand.

This repository is the plugin marketplace. It carries two tiers.

---

## Install

**Install ONE tier. Never both on the same account.**

1. Open the Claude desktop app.
2. Go to **Settings → Plugins**.
3. Top right, click **Add**, then **Add marketplace**.
4. Enter: `zoxiro/plugins`
5. Once the marketplace is added, install the tier you were given:

   - **Zoxiro Core** — the wholesaler tier. Deal sourcing, daily inbox review
     and admin, ARV and maximum-allowable-offer screening, a back-of-napkin
     creative screen for Sub-To and seller-carry leads, and deal pipeline/CRM.

   - **Zoxiro Operator** — the investor tier. Everything in Core, plus deal
     Sourcing with buy-box ranking and outreach prep, institutional 9-step
     Underwriting with Excel models, and a self-auditing health check.

## Then turn it on

Connect **Gmail**, **Google Calendar** and **Google Drive** first, in
**Settings → Connectors**. Do this *before* you start setup — a chat only sees
the connections that existed when it started.

Then open a new chat and type:

```
set up
```

Answer the questions it asks — your company, what you invest in, your markets.
You're finished when you see **"Looks good — take me home."** Not before. If it
goes quiet partway through, type `continue setup`.

Lost at any point? Type `home` or `what can you do?`
